# Registros de decisão de arquitetura (ADR)

Cada decisão importante fica num arquivo numerado `NNNN-titulo-curto.md`, com
contexto, decisão, alternativas e consequências. Um ADR aceito não é editado: se a
decisão mudar, crie um novo ADR que substitui o anterior e atualize o status do antigo.

| ADR | Título | Status |
|---|---|---|
